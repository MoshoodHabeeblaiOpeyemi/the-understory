You type `git commit -m "fix typo"` and press Enter. Something happens in
under a tenth of a second. Today we slow that moment down and watch every
gear turn.

## The three doors

Your Enter keystroke doesn't go to Git directly. It goes to the **shell** —
the program whose whole job is listening to your keyboard. The shell reads
the line, splits it into words, and makes a decision:

- Is the first word a program I know? Then run it.
- If not, is it a built-in command? Do that instead.
- If neither, say so honestly: `command not found`.

Git never even hears about it unless the shell decides to pass the message.

## Why this matters for the next 166 days

Once you see the shell as a *translator* — not magic — every tool in this
course stops being a black box. The terminal stops being a place where
scary things happen and becomes what it really is: a conversation.
